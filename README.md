# Simple Interest Calculator 🧮

Una aplicación de consola escrita en Python que permite calcular de forma rápida 
y precisa el interés simple acumulado sobre un capital, ideal para proyecciones 
financieras básicas y aprendizaje de lógica matemática.

## 📖 Descripción
Este proyecto es una herramienta sencilla pero eficaz para calcular el interés 
ganado o pagado basándose en un capital inicial, una tasa de interés anual 
y el tiempo en años.

## ➗ Fórmula Utilizada
El programa utiliza la fórmula estándar de interés simple:

I = P * r * t

Donde:
* I: Interés simple obtenido.
* P: Capital principal (monto inicial).
* r: Tasa de interés anual (en decimal).
* t: Tiempo (período en años).

---

## 🛠 Requisitos
* Python 3.x (Se recomienda la versión 3.8 o superior).
* No requiere librerías externas.

## 🚀 Instalación
1. Clona el repositorio:
   git clone https://github.com/tu-usuario/simple-interest-calculator.git
2. Navega al directorio del proyecto:
   cd simple-interest-calculator

## 💻 Uso
Para iniciar la calculadora, ejecuta el siguiente comando:
python main.py
